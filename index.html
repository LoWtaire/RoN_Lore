Navigation

Clique sur une carte mission pour ouvrir sa fiche détaillée. La touche Escape ferme les panneaux et les modals ouverts.

Recherche

La recherche filtre par nom de mission, tag ou texte de brief. Elle se combine avec les filtres avancés.

Filtres

Le bouton Filtre permet de cocher des tags. Le mode OU garde les cartes avec au moins un tag, le mode ET exige tous les tags cochés.

Tags

Dans une fiche mission, + Ajouter un tag permet de choisir un tag existant ou d'en créer un nouveau. Clic droit sur un tag pour le retirer.

Gestion

Dans Paramètres > Tags, le crayon renomme un tag et change sa couleur. La poubelle supprime le tag partout après confirmation.

Couleurs

Tu peux utiliser une couleur prédéfinie ou le sélecteur libre. Le bouton ⇩ enregistre une couleur custom dans les emplacements disponibles.
